# Railway quick setup

1. Push this folder to GitHub.
2. Railway → New Project → Deploy from GitHub Repo.
3. Select the repository.
4. Variables → add DISCORD_TOKEN, CLIENT_ID, OWNER_ID, LTC_ADDRESS.
5. Deploy.
6. No build/start commands need to be entered manually.
7. Future GitHub pushes redeploy automatically when GitHub auto-deploy is enabled for the service.
